# ADR-0021: 长期/触发式项归策略层（不进 TODO）

- Status: accepted
- Date: 2026-10-17

## 背景

2026-10-17 待办盘点：`TODO.md` 达 **150/160** 行，其中「搁置」区 **12 项**与在途项混放。这些项的共同点
不是"忘了做"，而是**现在没有立项条件**——缺真实语料、缺第二语言包、待作者拍板、或属长期方向。
保留待办身份只会：① 与在途项争注意力；② 每轮被重复论证一次；③ 占用容量上限。

作者定调（2026-10-17）："长期规划落入的也不算待办了，算是一种策略，应该进决策。"

## 决策

1. **TODO 只收"现在就能做"的项**（在途批次 / 现有缺陷 / 基础设施 / 预算登记）。
2. 触发式、长期规划项**不进 TODO**，登记在本档「决策表」：每项只留「结论 + 为什么现在不做 + 触发条件 + 链」。
3. **触发出现时按体量取回**：小项立 `TODO.md` 一项、大项立 `ROADMAP.md` 条目；决策实现后删本表对应行，
   **表空即删本 ADR**（与 `decisions/`「完成即删」一致）。
4. 一并确立**证据档位策略**（本档多处依赖）：C 条款/检查按 **A 档**（取得原文句 ⇒ `default=true`）/
   **B 档**（权威转述 ⇒ `default=false`）/ **C 档**（有反证 ⇒ 不实现）划分；B 档转默认开需**取得原文句**
   或**更大真实语料零误报**，不以"看起来对"升档。

## 权衡

- **代价**：触发条件靠人记，本档不是待办队列、不会自动提醒；靠"触发式项取回"纪律 + 定期盘点核对。
- **被否备选**：留在 `TODO.md`「搁置」区——已试过一轮，占约 1/3 容量、与在途项争注意力、每轮被重复论证
  （本轮盘点即证据）。
- **被否备选**：直接删——会丢"为什么不做"的判据，未来重新调研同一问题（S2 已是第二次评估）。
